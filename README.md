## 🇧🇷 Webscraping-news-volatility-email 🇺🇸

This repository was created with the intent of extracting data from an economic calendar on the investing.com website. It retrieves the main news items (those with a three-star volatility rating) and sends them via email.

---

## 🎯 Project Scope

The primary goal is to automate the monitoring and delivery of high-impact economic news directly to the user's inbox.

### ⚙️ Functionality

* **Data Extraction:** Scrapes economic calendar data from investing.com.
* **Volatility Filter:** Targets and retrieves only the news items flagged with the **three-star (high volatility) rating**.
* **Email Delivery:** Formats and sends the extracted daily news summary via email.
